## 🌟 Overview

**Envoy** is an autonomous AI agent designed to democratize professional branding. It generates customized, ATS-friendly resumes, academic CVs, and developer portfolios from scratch—or upgrades your existing documents to align perfectly with industry standards, target job sectors, and your unique background.

---

## 🔥 Key Features

* **🤖 Autonomous Career Agent:** Tailors content dynamically based on target job descriptions, domain expectations, and user preferences.
* **🎨 Modern Template Library:** Free, customizable templates for developers, designers, corporate roles, and academia.
* **⚡ Document Enhancement Engine:** Upload existing PDFs/Word documents to automatically reformat, rewrite, and optimize keywords for ATS compatibility.
* **🌐 Web Portfolio Generation:** Converts raw resume data into clean, modern, deployable web portfolios.
* **🔒 Privacy-First & Free:** Zero paywalls, zero locked features—fully open-source.
